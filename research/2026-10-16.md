## 入选新闻与信源

1. [Meta开放Muse Spark权重，8160亿参数模型支持百万上下文](https://research.meta.ai/blog/muse-spark-open)（Meta；10.15开放）
   Meta发布Muse Spark Open，总参数8160亿、每词元激活420亿，原生支持多模态输入与百万词元上下文。权重及多家推理平台服务同步提供；本地演示使用两台各配512GB统一内存的M5 Ultra Mac Studio。模型采用附商业条件的Muse Model License，开发者可自主部署，但不是无条件开放的Apache 2.0许可。

2. [库克称苹果智能计划月底在华测试，首批不含Siri AI](https://finance.sina.com.cn/jjxw/2026-10-15/doc-inivhyan4724388.shtml)（新浪科技；10.15采访）
   库克在上海接受采访时表示，苹果智能及相关阿里千问模型已获批准，计划于10月晚些时候在中国推出测试版。首批核心功能包括实时翻译、写作工具和照片清理，Siri AI不在此次范围内。这是中国区测试版的时间与功能预告，目前还不是面向所有用户的正式上线。

3. [Nemotron 3.5双模型开放，Bolt瞄准24GB显存本地智能体](https://blogs.nvidia.com/blog/nemotron-3-5-super-vl/)（NVIDIA；10.15（美）发布）
   英伟达发布Nemotron 3.5 Super VL与Bolt。Super VL为1200亿总参数、120亿激活的视觉语言模型，支持百万词元上下文；Bolt为740亿总参数、90亿激活，采用原生2bit量化，面向24GB显存设备运行本地智能体。两者权重已提供；更小的Bolt E4B则计划10月23日推出。独立评测的分数与词元效率见模型脉搏。

4. [FLUX.3 Image Klein开放权重，图像编辑支持十张参考图](https://bfl.ai/blog/flux-3-image-klein)（Black Forest Labs；10.15（美）开放）
   Black Forest Labs开放FLUX.3 Image Klein基础版及蒸馏版权重，并提供API，覆盖文生图、编辑、最多十张参考图和边界框控制，支持原生4K输出。生成器为56亿参数，不含文本编码器；INT8配置可在8GB显存运行。权重采用FLUX Kommunity License，年收入低于500万美元的组织可按条款免费商用，其他商业用途需另行许可。

5. [微软完成MAI-Base-2预训练，2.8万亿参数模型仍在后训练](https://microsoft.ai/news/frontier-pre-training-at-microsoft-ai/)（Microsoft AI；10.15（美）披露）
   微软披露MAI-Base-2已完成预训练，采用原生视觉MoE架构，总参数2.8万亿、激活800亿。预训练使用约1.6万块GB200，历时38天。模型现进入后训练阶段，尚未开放公众API或权重。微软同时介绍自有训练基础设施与预训练效率研究，本次发布重点是研发进展，并非一个已可调用的新产品。

6. [Ramp融资18.5亿美元，估值升至600亿美元](https://www.prnewswire.com/news-releases/ramp-reaches-60-billion-valuation-as-annualized-revenue-tops-2-billion-302909315.html)（Ramp / PRNewswire；10.15（美）宣布）
   AI财务运营平台Ramp宣布完成18.5亿美元新增股权融资，由Dragoneer领投，Thrive Capital、Founders Fund等共同领投，估值600亿美元。公司称年化收入已超过20亿美元并实现正现金流，正把应收账款自动化、AI用量支出管理和模型路由等工具接入企业财务流程。年化收入按近期经营速度推算，不是已实现的全年收入。

7. [台积电维持600—640亿美元资本预算，AI需求支撑扩产](https://investor.tsmc.com/english/quarterly-results/2026/q3)（台积电；10.15财报）
   台积电第三季度收入467.2亿美元，第四季度收入指引为523亿—543亿美元。公司维持2026年600亿—640亿美元资本支出预算，并预计2027年N2年度产能较今年增加一倍以上。管理层称，智能体及开放模型采用继续带动先进制程需求；本次资本预算是重申，而非新一轮上调。

8. [小米介绍MiDashengLM-Spatial，让音频模型识别声音方位](https://github.com/xiaomi-research/midashenglm-spatial)（小米 / GitHub；10.15介绍）
   小米介绍已开放权重与推理代码的MiDashengLM-Spatial，将音频语义理解与空间感知结合。模型可利用双耳音频，识别声源方位、运动与重叠声音事件，为机器人和可穿戴设备理解周围声场提供底座。项目采用Apache 2.0许可；其官方基准包含不同音频输入设置，需结合具体任务判断表现。

9. [亚马逊推出74.99美元Bee Frontier，AI记忆设备扩展形态](https://www.aboutamazon.com/news/devices/amazon-personal-ai-bee-frontier-bee-eclipse)（Amazon；10.15（美）发布）
   亚马逊推出可佩戴或夹挂的Bee Frontier，售价74.99美元，基础功能含对话总结与14天记忆。手机磁吸款Bee Eclipse起价99.99美元，将于稍后上市；Bee Pro订阅为每月11.99美元，可扩展集成与功能。亚马逊称原始音频实时处理后删除，文字转录与摘要则可加密保存；设备配有实体按钮与状态灯。

2. [Nemotron新评测：Super得分提升，输出词元减少约六成](https://artificialanalysis.ai/articles/nemotron-3-5-super-and-bolt)
   AA新评测中，Nemotron 3.5 Super VL智能指数为26.5，前代Super为12.8；每项指数任务平均输出由约11.4万降至4.6万词元。Bolt为21.4分、约8.2万输出词元。Super在本次评测中兼顾分数和词元效率，但指数分数不是准确率，输出减少也不等同所有任务费用同比例下降。
   数据：Nemotron 3.5 Super VL / 120B · 12B激活 / 26.5 / 4.6万；Nemotron 3.5 Bolt / 74B · 9B激活 / 21.4 / 8.2万；Nemotron 3 Super / 前代对照 / 12.8 / 11.4万。
   核查：AA智能指数v4.3.2，分数与词元量均按发布文口径；不是终端任务成功率。输出词元包含评测生成消耗，不是API单价；未将特定预发布端点的速度泛化为所有部署性能。

3. [N1X笔记本回放18.7分钟，接近DGX Spark](https://artificialanalysis.ai/articles/nvidia-rtx-spark-agentperf-local)
   同一Qwen3.8 27B Xhigh本地智能体回放中，RTX Spark N1X笔记本耗时18.7分钟，DGX Spark为17.3分钟，M5 Pro MacBook Pro为37.6分钟。结果比较的是固定工作负载的模型响应耗时，不是任务正确率；不同系统采用各自优化配置，不能解读成纯芯片能力翻倍。
   数据：回放耗时 / RTX Spark N1X / 18.7 / 分钟 · 128GB；回放耗时 / DGX Spark / 17.3 / 分钟 · 128GB；回放耗时 / M5 Pro MacBook / 37.6 / 分钟 · 64GB。
   核查：原型Surface Laptop Ultra、插电高性能模式；8段任务、168轮、固定约3.1万输出词元，不含工具执行时间。各设备运行时、4bit格式与投机解码方案不同，属于整机优化方案比较。
