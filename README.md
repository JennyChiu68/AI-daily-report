# AI前沿日报

金十 AI 前沿日报的完整前台源码、品牌素材、历史信源核查记录，以及接入金十现有内容管理后台的功能需求。

当前冻结基准为 **2026 年 11 月 17 日**。当前实现可以展示日报、渲染多种模型图表，并在浏览器导出约 1MiB 的完整 JPG。日报内容目前保存在代码中；自动联网生成、后台编辑、会员鉴权与定时发布属于待接入金十后台的开发需求，详见需求书。

## 本地运行

需要 Node.js >= 22.13.0 与 npm。

```bash
npm ci
npm run dev
```

打开终端提示的本地地址（通常为 http://localhost:3000）。

```bash
npm run build
npm run start
npm test
```

`npm test` 会先构建，再检查服务端页面、内容结构、来源布局及 JPG 导出相关回归规则。测试中的标题、日期和数据对应冻结样例；更新日报时需一并更新预期内容。

当前前台运行不需要 API 密钥或数据库。`.openai/hosting.json` 仅保留无绑定的本地配置，未携带原托管项目 ID。Vite / Vinext 构建使用 Cloudflare Worker 入口；如部署至其他平台，应由技术按目标环境调整适配。

## 日报编辑规则

- 标题兼顾多条日内重要内容，有吸引力且准确；导读应覆盖主要看点。
- 今日概览提取多个独立重点并做归纳，不直接照抄快讯，也不把同一主题拆开凑数。
- 模型脉搏从既有信源中按热度和真实变动选择，不限制每日固定内容与个数。主要跟踪 OpenRouter、Artificial Analysis、Arena、LLM Stats、Kilo 等，按来源更新与实际热点取舍。
- 依据内容选用排行条形图、对照表和指标卡等形式，保留图表多样性。
- 快讯分类标签统一使用两个汉字，如“评测”“电力”“并购”。
- 仅为会影响理解、且标题/单位/正文无法说明的数据口径添加简短注释；来源、日期与必要授权署名紧凑呈现。
- 保留原文核查依据，区分官方公告、媒体报道、预测与已发生事实。商业机构人员称“负责人”。
- 不使用财联社、科创板日报作为展示消息源。涉及中美谈判以中国官方媒体口径为准。
